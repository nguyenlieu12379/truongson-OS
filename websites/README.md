# Websites

Every website project lives in its own folder, named after its owner:

```
websites/
  <owner>/
    <site-name>/
      README.md    # what it is, how to edit, how to deploy
      index.html
      assets/
```

## Add a site

Create `websites/<owner>/<site-name>/`, add a row above, and give the site its own README.
